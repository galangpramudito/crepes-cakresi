PANDUAN MEMASUKKAN FOTO/GAMBAR KE DALAM WEBSITE
=====================================================

1. LOKASI FOLDER:
   Masukkan semua foto (JPG, PNG, atau WebP) ke dalam folder ini:
   -> crewebs/public/images/

   Pakai nama file TANPA SPASI, huruf kecil, pisah dengan tanda minus.
   Contoh: crepes-meses-keju.jpg  (bukan "WhatsApp Image 2026....jpeg")

2. FOTO YANG DIPAKAI SEKARANG:
   - hero-mas-resi.jpg   -> Foto besar di bagian paling atas (hero)
   - live-cooking.jpg    -> Foto di bagian Catering
   - gerobak-taman.jpg   -> Galeri
   - gerobak-malam.jpg   -> Galeri
   - gerobak-sore.jpg    -> Galeri

3. CARA MENGGANTI:
   Buka file: crewebs/src/data/storeData.js

   a) Foto hero & catering, ubah bagian:
      images: {
        hero: '/images/hero-mas-resi.jpg',
        catering: '/images/live-cooking.jpg',
        ...
      }

   b) Foto galeri, ubah daftar GALLERY:
      {
        url: '/images/nama-foto-baru.jpg',
        title: 'Judul singkat',
        desc: 'Keterangan singkat'
      }
      Galeri paling pas berisi 4 foto (foto pertama tampil paling besar).

4. TIPS:
   - Ukuran file di bawah 300KB agar website cepat dibuka.
   - Foto hero paling bagus posisi BERDIRI (potret), wajah & crepes terlihat jelas.
   - Foto crepes close-up (tampak topping) sangat disarankan untuk ditambahkan.
